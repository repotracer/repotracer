RepoTracer

Six marks for the read-only repo scout that finds the files before Codex starts fixing. Every variant is one idea, monochrome, built on a 100×100 grid so it holds from favicon to billboard. The accent-lit element in each is the hit — the validated file:line the scout hands back.

Breach

Pure geometric

A closed repository boundary with one rounded opening — and the located node sitting exactly in the gap. Reads as 'the thing you were looking for, brought out'. Strongest at 16px of any of these; the silhouette survives a favicon.

Scan

Dot matrix

A field of files at 22% opacity. One route through it is lit, ending in a solid hit. This is the product literally diagrammed: most of the repo stays untouched, one path gets traced.

Ledger

Line system
