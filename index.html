Why this exists

I came across a paper from Microsoft on delegating repository exploration. The short version: you can cut cost by letting a smaller model do the searching, when the task actually calls for it.

So I built a tool for myself. After a few rounds of refinement I noticed my limits were lasting a lot longer. But how I feel about my rate limit is not evidence, so I ran benchmarks — real prompts in real repositories I actually work in, so the numbers would reflect the real world, plus SWE-bench tasks just in case.

The results were better than the hunch. On a real bug-fix task in a production repository, the complete bill dropped 62.7% and the expensive model took in 74.9% fewer tokens — with Luna's own usage counted in the total.

That same run also scored slightly worse on quality. It's published on the benchmark page next to the wins, because a saving you can't audit isn't worth anything.

Worth noting the paper tested very small models. On these benchmarks the main model was Sol and the scout was Luna.

How it works

Codex calls one tool. RepoTracer searches, validates every citation against the file, and hands back the locations worth opening.

Benchmarks

Every study came in cheaper — measured on the whole task, with the scout's own usage added in, not on a token counter. The rule: if the invoice didn't shrink, it isn't a saving.

RepoTracer is a beta. It reduced complete provider cost in every run above, but the Google task also exposed a real quality regression: RepoTracer localized the right files and the parent agent then tested a duplicated fixture instead of the production module. Aggregate model input often rises too — the saving comes from moving search to a cheaper model, not from using fewer tokens. The launch gate of 30 independent tasks is not met.

The scout cannot write

Not a policy or a prompt instruction — the binary has no write tool compiled into it.

It can

  • Read files
  • Search content
  • Expand globs
  • Return file:line citations

It cannot

  • Edit files
  • Delete files
  • Write patches
  • Push code
