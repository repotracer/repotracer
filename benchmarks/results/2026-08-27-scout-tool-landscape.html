Tool landscape / 27 August 2026

Search broadly. Test one thing.

Forty-plus GitHub projects collapse to one useful next move: test the smallest CodeGraph surface against Scout's current file tools, then keep only measured gains.

scope local read-only retrieval ranking RepoTracer fit first test Colby CodeGraph index policy existing only
Decision 001 / diagnostic only

Add one codegraph_explore tool to the candidate arm.

Keep Read, Glob, and Grep unchanged. Do not expose index maintenance, lower-level graph commands, or prompt recipes. If no compatible index exists, the tool is unavailable; RepoTracer never creates one.

  1. Highest upside on cross-file flow and impact questions.
  2. One composite tool fits Scout's small surface.
  3. Strong source-level evidence and explicit output bounds.
  4. Known negative evidence makes the test worth running.
Important contradiction. CodeGraph's own multi-turn study reports 82% more retrieval context resident than file access across seven repositories, even while it reports fewer processed tokens, lower average cost, less time, and fewer tool calls. Throughput and context occupancy can move in opposite directions. This experiment measures both.

02Use tools by context, not as a bundle

A / FLOW

Cross-file architecture or impact

Try CodeGraph first. Measure source sufficiency and residual context before adding any second graph or semantic index.

B / UNKNOWN WORDING

Concept known, symbol unknown

Probe is the zero-index fallback candidate. CocoIndex or grepai come later only if embeddings beat it enough to pay for state.

C / KNOWN SHAPE

Syntax or API pattern

ast-grep. It should appear only when the request can be expressed structurally; otherwise current Grep is clearer.

D / KNOWN SYMBOL

Definition, references, implementation

Use an existing LSP or SCIP index. Do not build semantic state inside RepoTracer just to answer one query.

E / HUGE CORPUS

Very large or multi-repository exact search

Zoekt earns a test only after native Grep latency fails a measured threshold. It is scale infrastructure, not free semantics.

F / SECURITY

Taint, policy, or vulnerability flow

Semgrep or CodeQL as explicit specialists. Their setup and schemas should never tax ordinary Scout requests.

Rejected architecture: expose CodeGraph, Probe, ast-grep, semantic search, symbol search, and a reducer together. The model would spend turns choosing tools, every schema would consume context, and an A/B could not identify the cause of a win or loss.

03First experiment

A small paired diagnostic answers whether graph retrieval changes Scout's mechanism. It does not approve a release.

Control

  • Current Read, Glob, Grep
  • Same repository snapshot and hidden index directory
  • No shell or CodeGraph route
  • Same Codex subscription model, effort, prompts, and task order

Candidate

  • Everything in control
  • Plus codegraph_explore(query)
  • Existing compatible index only
  • No init, watch, update, network, or lower-level graph tools
Select eight preregistered tasks.

Four cross-file flows, two change-impact or caller questions, and two exact-text/config negative controls. Use known required paths without exposing them to the model.

Run three randomized repeats per arm.

48 complete trials. Infrastructure failure resamples both sides; agent timeout, bad evidence, or wrong answer stays a model failure.

Measure cold and warm separately.

Cold includes process attach. Warm pre-starts CodeGraph so retrieval is not confused with daemon startup. Index build, disk, memory, and refresh stay separate adoption metrics.

Capture complete economics and context.

Provider USD, complete wall time, tool calls, output bytes, truncation, citations, final Scout input tokens, and retrieval context still resident at synthesis.

Grade blind, then unblind.

Quality and required behavior first. Only then inspect arm, cost, time, tool choice, and the mechanism behind each paired delta.

Contamination rule. The model gets no Bash tool, so the adapter is the only valid CodeGraph path. Keep the same index on disk in both arms and verify that no uncounted CLI or network output entered either trajectory.

  1. Colby CodeGraph source and READMEComposite explore interface, SQLite graph, source extraction, freshness behavior, and installation.
  2. CodeGraph residual context studyVendor-run seven-repository, three-turn Sonnet campaign; contamination discovery; higher residual occupancy and simultaneous throughput savings.

  5. ast-grep documentationStructural AST search and rewrite across languages.
  6. SCIP source and protocolDefinitions, references, implementations, bindings, and language indexers.
  7. Zoekt sourceTrigram indexing, symbol-aware ranking, APIs, and local/service deployment.
  8. RTK savings methodologySeparates bytes filtered, estimated tokens, and actual bill impact; useful measurement discipline, not a Scout retrieval solution.
  9. RepoTracer benchmark architectureQuality-cost-time order, blind review, paired task-cluster analysis, release thresholds, and the 30-task floor.
