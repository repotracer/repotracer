Major iteration / parent routing

No selective router is ready to ship.

Always calling Scout exposed a real economic upside on one complex task. It also made the localized task 174% slower and cannot be enforced from RepoTracer without the instruction-only fix this study excluded.

12 complete Sol runs · 111 deterministic route decisions · 36 model boundary decisions · 18 Scout fast-tier runs · real Codex subscription
Decision

No routing product change. Treat always-Scout as an upper bound, not a policy. With approval, run a broader scoped Luna medium fast/priority-tier pilot; do not change the default from nine pairs.

Quality review

An arm-blind reviewer scored all 12 complete outputs. All six localized answers were fully correct. Five of the six runtime patches scored 2/4 because they lost completed sibling payloads at the final Scout result, failed to clean provider subprocess descendants, or miscounted interrupted work. The one 4/4 patch was in always-Scout: it closed batch cancellation, observable partial results, direct search cleanup, provider process groups, and regressions together.

Scout evidence itself was sound: 100% of citations resolved to valid ranges, mean expected-path recall was 87.5%, and every Scout call completed. Six independent targeted runs of cargo test -p repotracer-core -p repotracer-repo-tools -p repotracer passed.

Limits and approval gate

  • Two complete tasks cannot establish a general always-Scout policy.
  • The focused Sol arms used a bounded dynamic-tool harness; complete tasks used the real RepoTracer MCP path.
  • Concurrent Scout calls support exact arm-level billing, not defensible per-trial Scout cost attribution.
  • The synthetic runtime task had targeted tests and blind review, but no independent hidden behavioral fixture.
  • RepoTracer has no API today to inject a speculative Scout result into a parent turn or force a selective tool choice.
Approval requested

Approve a broader scoped fast/priority-tier Scout pilot only. Do not approve a parent-routing code change from this evidence.
